# Задания на тексты (контент-брифы) — ChikChirik

*15.10.2026. Частотность запросов оценена качественно по выдаче (SEO-инструменты не подключены). Каждая страница делается на трёх языках: RU (`/`), KZ (`/kz/`), EN (`/en/`).*

**Общие правила для всех страниц**
- Название бренда — только **ChikChirik** (слитно).
- Тон — на «ты», как на главной; коротко и по делу.
- Не придумывать цифры. Цены, число специалистов, сроки — только из данных приложения (см. «Что нужно из приложения»).
- Каждая страница: H1 с главным запросом и городом, лид 2–3 предложения, услуги, «как найти» (3 шага), цена (что влияет + реальные диапазоны, когда будут), как выбрать, FAQ 4–6 вопросов, CTA (App Store / Google Play / Telegram-бот), ссылки на 2 соседние категории.
- Title ≤ 60–65 символов, description ≤ 160.
- Чем выигрываем у Kaspi Объявлений и OLX (они в топе): только креатив, портфолио, отклики сами приходят, чат, бесплатно для заказчика.
