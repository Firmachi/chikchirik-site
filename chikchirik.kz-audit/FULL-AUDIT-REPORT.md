## Что было найдено и исправлено

### Критично
1. **После переезда на Vercel боты без JavaScript видели пустую страницу.** Title, description, canonical, Open Graph и JSON-LD лежали внутри `<helmet>` и попадали в `<head>` только после выполнения скрипта. Telegram, WhatsApp и Facebook не показывали превью ссылки, а Яндекс, GPTBot, ClaudeBot и Perplexity видели около 350 символов шаблона с `{{ }}`.
   → **Исправлено:** сборка `scripts/build.mjs` переносит SEO-теги прямо в `<head>`. Пре-рендер в headless Chrome добавляет статическую копию текста страницы `#ssr`, около 2 700 символов: заголовки h1–h3, FAQ, ссылки, alt картинок. Её видят только клиенты без JS, у обычных посетителей она скрыта. Содержимое то же самое, поэтому это не клоакинг.

### Высокий приоритет
2. **Фото весили 13,4 МБ** (8 PNG по 1–2 МБ, исходники 1023–1122 px). → Переведены в WebP шириной 800 px, теперь **0,54 МБ** (в 25 раз легче). Картинки ниже первого экрана грузятся лениво (`loading="lazy"`).
3. **Нет `lang` у `<html>`.** → Добавлен `lang="ru"`.
4. **Ошибка JS при переходе в «Документы»** (`componentDidUpdate`: «Cannot read properties of undefined (reading 'page')»): анимации после переключения страниц могли не запускаться. → Исправлено в обоих исходниках.

### Средний приоритет
5. Нет `preconnect` к CDN (unpkg, cdnjs, Google Fonts). → Добавлены.
6. Нет `llms.txt`. → Добавлен `/llms.txt`: краткое описание сервиса, ссылки, контакты.
7. `sitemap.xml` → `lastmod` обновлён.

## Что осталось (нужны решения или контент от вас)
- **Отдельные URL для документов** (`/terms`, `/privacy`, `/consent`, `/offer`). Сейчас они открываются внутри страницы без адреса, и поисковики их не индексируют. Для приложения в App Store и Google Play нужна прямая ссылка на политику конфиденциальности.
- **Ключевые слова в H1.** «Находи своих через ChikChirik» не содержит запроса. Вариант: оставить слоган, а ключ «Креативные специалисты Казахстана» оформить заголовком над ним (сейчас это бейдж).
- **Блок «О сервисе»** на 150–250 слов: кто стоит за проектом (ТОО «Firmachi»), с какого года, города, как устроены оплата и безопасность. Это нужно для E-E-A-T.
- **Даты у цифр** («5 040 пользователей — на октябрь 2026»).
- **Страницы категорий** (`/videografy`, `/fotografy`, `/dizajnery`, `/motion`, `/smm`) и городов (`/almaty`, `/astana`) — главный источник органического трафика на будущее.
- **Казахская версия** `/kz/` с hreflang.
- **Подключить Google Search Console и Яндекс Вебмастер**, отправить sitemap. Добавить аналитику (GA4 или Яндекс Метрика).
- **Производительность:** страница рисуется скриптом (React с unpkg + GSAP + Lenis). Если нужна максимальная скорость, можно перенести React и GSAP на свой домен.
- Замерить Core Web Vitals в PageSpeed. Дневная квота бесплатного API во время аудита была исчерпана.
